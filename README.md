#HandiVoice

A Smart Wearable Assistive Communication System Using Gesture Recognition

From Hand Gestures to Accessible Communication

HandiVoice is a wearable assistive technology concept that combines finger-flex sensors, hand-motion sensing, embedded processing, and a web dashboard to recognize a defined set of hand gestures and convert recognized gestures into text and speech.

The current prototype focuses on sensor-based gesture recognition, system integration, and accessible communication, with further validation required to expand its gesture vocabulary and real-world performance.
